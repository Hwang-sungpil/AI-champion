# 산출물 1 — 3부처 보도자료 검색 정적 페이지

## 요구사항별 구현
1. **부처 카드 표시**: `보도자료데이터.json`의 3건(번호·부처·제목·본문)을 읽고, 부처·제목·본문 요약을 카드로 표시합니다. `원문 보기`로 전체 본문을 확인합니다.
2. **키워드 검색**: 부처·제목·본문에 대한 부분 문자열 검색, 실시간 `결과 N건` 표시, 부처별 버튼 필터, 초기화 버튼을 지원합니다.
3. **외부 리소스**: Unsplash 외부 이미지를 `<img>`로 페이지에 표시하고, 출처 링크 및 이미지 로딩 실패 안내를 제공합니다. 사건 현장 사진이 아닌 참고 이미지입니다.
4. **배포**: GitHub 저장소 루트에 파일 6개를 업로드한 뒤 Netlify의 Import existing project → GitHub로 연결합니다. Build command 비움, Publish directory `.`.

## 파일 구성
- `index.html`: 메인 페이지
- `style.css`: 스타일/반응형
- `script.js`: 카드 렌더링, 검색, 필터, 데이터 로딩
- `보도자료데이터.json`: 제공된 원본 JSON (3건)
- `data.js`: 로컬 파일 직접 열기 환경의 JSON 동일 내용 대체 로더
- `README.md`: 사용법

## 테스트
- `index.html` 더블클릭(file://) 시 카드 3건 표시 (data.js 사용)
- Netlify(https://)에서는 JSON을 우선 로드, 실패 시 data.js 사용
- 빈 검색어 → 결과 3건; `1,820` → 2건; `기상청` → 1건; `없는검색어` → 0건
- 외부 이미지 로딩은 인터넷 연결 및 외부 서비스 상태에 따라 달라질 수 있음

**배포 URL은 GitHub/Netlify 연결 후 생성되며 이 패키지에는 포함되지 않습니다.** `cdsa.site` 도메인을 사용하지 않고 제출 후 1개월 이상 배포 URL을 유지하세요.
